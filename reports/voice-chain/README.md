# 4090 A 侧语音链路实测

2026-11-14，真实 RTX 4090 D。通过正在运行的 HTTP 服务提交固定合成中文 WAV，再分别完成文字续聊、重置隔离和在途停止。输入是合成录音，不能作为真实麦克风识别率评测。

## 最终采样链路

| 项目 | 实测 |
| --- | --- |
| ASR 文本 | 我叫小林，今天考试没考好，我很难过。 |
| 用户情绪 / 表达意图 | sadness / gentle，0.75 |
| ASR 阶段 | 11.139s |
| LLM 阶段 | 12.194s |
| TTS 阶段 | 48.494s |
| 服务端总生成时间 | 71.830s，包含逐阶段加载模型 |
| 返回语音 | 24kHz、单声道、35.92s WAV |
| 解码 | LLM greedy；TTS talker/subtalker sampling、seed42、max2048 |

`chain-report.json` 中七项检查均通过：音频全链、文本全链、姓名承接、重置隔离、旧音频410、旧请求409、在途停止409。服务器 stop 回执为3.498ms，仅代表这一次后台响应，不代表浏览器500ms停播。

原始输入/输出为 `input-synthetic.wav`、`audio-turn.json`、`audio-reply.wav`、`text-turn.json`、`text-reply.wav`、`reset-turn.json`。`asr-stage.json` 与 `tts-stage.json` 保留模型来源、固定版本、生成配置、阶段显存和原始输出；`source-sha256.json` 将运行代码与当前文件内容关联。

## 必须保留的失败对照

同一133字回复、同一语气指令下，强制 greedy 的512/2048预算分别生成40.88/163.76秒音频，均跑到长度上限，不能作为完整语音成功证据。它们的原始报告保存在 `diagnostics/`；没有改写成成功的新结果。

改用上游默认采样后同一文本为35.92秒，真实 ASR 读回内容与回复一致（标点差异保留在 `sampled-audio-asr-roundtrip.json`）。最终 HTTP 返回音频与该独立对照 SHA-256 相同。固定验证脚本增加90秒音频时长回归限制，专门拒绝本例异常，不把它当作通用语速、准确率或性能标准。

当前仍是串行冷启动基线。低延迟、人工听感、真实麦克风、浏览器音画同步和完整数字人工程指标另行验证。服务端实际会话、录音和阶段日志保存在 `runs/`，本目录只公开固定合成测试材料。
