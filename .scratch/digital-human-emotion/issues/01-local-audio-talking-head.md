# 01: 本地音频驱动可见三维说话头

**What to build:** 在浏览器选择本地中文音频并播放，看到三维头部随节奏开合嘴，停顿和结束时闭嘴，形成无需模型或机器人在线的独立演示。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**State:** closed

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [x] 使用商业用途许可明确、包含所需面部形变参数的三维头部与音频，记录来源、版本和可用参数。
- [x] 页面能够启动、加载资源、播放和基础停止；显示加载、播放、完成或失败状态。
- [x] 固定音频的起止及停顿可见地驱动嘴部变化，结束后不继续运动；此票不宣称音素级唇形。
- [x] 表情、嘴部和后续注视经同一面部控制边界混合；参数帧包含发言标识、会话代次、帧序号、音频相对时间和归一化权重，保存可关联播放记录。
- [x] 从页面入口检查真实声音、可见嘴部和结束状态；无效资产、音频或资源缺失有明确反馈。
- [x] 记录本地渲染与音频基线，不下载或实现任何实体控制协议，也不预建硬件适配器。
