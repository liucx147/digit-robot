# 13: 复现原始学生开发集基线

**What to build:** 使用实际未适配学生批量预测开发集，输出逐条结果和可复核基线，冻结后续公平比较所需条件。

**Blocked by:** [02 本地原始学生完成连续中文文本对话](02-local-student-text-dialogue.md)；[12 封存可审计的七类研究数据版本](12-auditable-emotion-data-release.md)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 使用同一未经项目适配的学生基座，记录版本、提示、标签、上下文、解码和运行条件。
- [ ] 关闭记忆或固定同一档案快照，候选比较复用同样条件。
- [ ] 输出原始错误数、错误率、每类表现、宏平均F1、混淆矩阵及解析失败，无效输出按失败计分。
- [ ] 通过公开研究入口重跑得到可关联预测与报告，不修改开发集标签使结果变好。
- [ ] 本票只使用开发集，不打开或预测最终留出集；最终公平比较留到冻结候选后的统一终评。
