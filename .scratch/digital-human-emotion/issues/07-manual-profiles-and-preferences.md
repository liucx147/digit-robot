# 07: 手动档案和跨会话偏好增查改删

**What to build:** 用户在页面手动选择档案，明确保存、查看、修改和删除偏好；相关回复使用当前档案的有效值，重启后仍一致且不串用其他用户信息。

**Blocked by:** [03 浏览器输入文本得到情感语音和表情](03-text-to-expressive-avatar.md)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 手动创建或选择本地用户档案，界面展示当前档案；不引入人脸、声纹或其他自动身份识别。
- [ ] 以本地持久存储保存明确要求记住的称呼和交流偏好，默认采用SQLite，提供完整增查改删入口。
- [ ] 只将当前档案的有效字段注入对话，实际回复可验证偏好生效，而非仅验证数据库存在记录。
- [ ] 修改、删除或切换档案后，当前会话和重启后的实际回复不再把失效偏好作为仍有效的记忆；受控用例不重新提供旧值，并覆盖历史上下文与提示缓存残留。
- [ ] 两个档案切换、退出重启后读取、更新及删除行为一致，不发生偏好串用。
- [ ] 档案写入或读取失败有可见反馈，保留必要操作记录，不自动持久保存全部原始聊天。
