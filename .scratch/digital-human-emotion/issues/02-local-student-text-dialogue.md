# 02: 本地原始学生完成连续中文文本对话

**What to build:** 从命令行输入中文，使用实际本地学生模型获得用户文本情绪、共情回复及独立表达意图，连续两轮能够承接上下文；此入口供数字人和研究评测共同使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 优先验证Qwen3.5-4B；资源不满足时验证2B后备，记录实际型号、许可、版本、配置与资源情况，不写成预先保证可用。
- [ ] 使用未经本项目适配的原始学生，断网输入中文后输出七类用户情绪之一、回复文本和数字人表达意图。
- [ ] 用户情绪与表达意图区分，至少能演示理解悲伤后采用关切回应，而非把情绪标签直接当表情命令。
- [ ] 连续两轮承接本次会话上下文；会话重置后不混入旧会话内容。
- [ ] 字段缺失、枚举错误或过长输出触发有限重试或明确中性回退，保留原始失败；评测能够识别这些失败而非把回退当正确预测。
- [ ] 经公开文本入口验证结果和错误行为；冻结推理契约，不依赖教师数据、蒸馏结果、TTS或数字人页面。
