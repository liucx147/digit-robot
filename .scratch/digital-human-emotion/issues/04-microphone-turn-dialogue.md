# 04: 麦克风中文发言贯通数字人回应

**What to build:** 用户开始并结束一轮中文发言，本地ASR转写后进入现有对话、合成与三维播放链，完成一次真实语音交互。

**Blocked by:** [03 浏览器输入文本得到情感语音和表情](03-text-to-expressive-avatar.md)

**Status:** ready-for-agent

**State:** open

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [x] 优先验证预训练Qwen3-ASR-0.6B，记录模型许可、运行版本和实际转写能力，不训练ASR。
- [x] 提供明确的开始与结束发言入口，区分监听、转写、生成、播放和完成；采用轮次交互。
- [ ] 真实麦克风与固定中文录音均可得到转写并触发完整数字人回应。
- [x] 空录音、麦克风权限拒绝和无法转写有明确反馈，不用空文本继续伪造成功对话。
- [x] 承接发言标识、会话代次和错误信息，方便后续停止与恢复使用同一公开交互入口。
- [x] 保留从实际输入到有意义语音输出的计时记录，但三秒目标不是此票的硬门槛。
