# 16: 有界追加实验并冻结终评候选

**What to build:** 依据开发集完成零至两轮有记录的追加实验，形成候选选择、累计成本与封存清单，明确何时停止探索。

**Blocked by:** [15 首轮单卡LoRA训练与开发集对照](15-first-single-gpu-distillation.md)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 只依据开发集决定是否追加和选取候选，可以直接选择首轮候选，不强制执行两轮。
- [ ] 最多两轮追加，每轮研究工作量暂估1至2周，保留修改假设、数据和配置版本、预测及失败记录。
- [ ] 不重置100元累计教师预算，不将开发样本并入训练，不打开最终留出预测。
- [ ] 达到轮次或预算上限即停止并记录真实结论，追加有限而非持续探索直到成功。
- [ ] 冻结一个终评候选和复现条件，保留原始基座及回退版本；候选选择不依赖数字人工程验收。
- [ ] 首轮约4至6周是研究安排，不当作数字人工程日期；用尽资源仍未达预期时提交负责人评审材料。
