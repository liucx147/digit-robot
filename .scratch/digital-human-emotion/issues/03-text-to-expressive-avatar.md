# 03: 浏览器输入文本得到情感语音和表情

**What to build:** 在数字人页面输入中文，得到本地学生回复，听到实际TTS语音，并看到与表达意图协调的表情及嘴部动作。

**State:** closed

**Category:** enhancement

## Acceptance criteria

- [x] 页面输入贯通本地对话、预训练TTS、音频播放和三维呈现，显示生成、播放、完成及失败状态。
- [x] 优先验证Qwen3-TTS-12Hz-1.7B-CustomVoice及固定音色，记录许可和本机能力，不训练TTS。
- [x] 按表达意图选择可用语气和面部表情，记录实际支持范围，不假定七类文本情绪天然等于七种表情。
- [x] 音频和动画关联同一发言及会话代次，使用实际音频播放位置作为同步基准，结果可回放核验。
- [x] 通过固定情绪文本检查可读回复、实际语音和可见表情协调，生成或合成失败不能显示为成功。
- [x] 根据前两票得到的运行和资产基线重估数字人剩余工作量，不沿用机器人8至12周估算。
