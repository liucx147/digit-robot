# 12: 封存可审计的七类研究数据版本

**What to build:** 从授权资源或原创文本到人工标注复核、去重划分、封存和审计报告形成可运行工作流，提供独立研究所需的数据版本。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 训练、开发和最终留出数据来源满足商业用途许可，记录来源与限制；不适配时使用已批准的原创或明确授权人工标注后备方案。
- [ ] 固定高兴、悲伤、愤怒、恐惧、惊讶、厌恶、中性七类定义，并冻结样本量、类别覆盖、标注和失败规则。
- [ ] 人工独立标注并复核分歧，教师不能是最终金标的唯一裁判；不看模型预测后删除难例。
- [ ] 训练、开发和最终留出隔离并去重，输出版本、分区与审核证据。
- [ ] 最终留出文本和金标不进入教师示例、训练或迭代选择，工作流拒绝把封存分区当训练或生成输入。
- [ ] 通过研究入口导入数据后生成可核验审计报告；不要求数字人页面或本地学生已可运行。
