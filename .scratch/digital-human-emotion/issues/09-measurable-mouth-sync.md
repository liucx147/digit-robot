# 09: 测量并达到可见嘴部同步门槛

**What to build:** 通过数字人播放冻结音频，采集可见嘴部与实际声音，给出逐事件误差报告，并将节奏嘴部调度修正到约定同步门槛。

**Blocked by:** [01 本地音频驱动可见三维说话头](01-local-audio-talking-head.md)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 冻结音频、预期起止和停顿事件、采样及判定规则，使用可关联时间基准采集画面和实际音频。
- [ ] 至少95%的全部固定预期事件相对音频偏差不超过200毫秒；实际嘴部可见变化是测量对象。
- [ ] 缺失、无法配对、提前或滞后超限均进入分母且按失败统计，另列诊断原因。
- [ ] 用人为缺失和边界偏差样例验证计分，不用内部参数时间一致或平均偏差冒充达标。
- [ ] 必要时修正播放时钟和动画调度，保留补偿前后证据，不升级为音素级口型。
- [ ] 提供可重复测量入口和报告，最终集成版本还需重新执行，不将单独说话头达标等同于完整系统验收。
