# 14: 累计100元内生成并审核教师材料

**What to build:** 从训练分区输入到教师调用、人工复核、合格材料导出和费用报告形成完整流程，持续共享所有轮次的100元预算。

**Blocked by:** [12 封存可审计的七类研究数据版本](12-auditable-emotion-data-release.md)

**Status:** ready-for-agent

**Category:** enhancement

**Parent:** [数字人优先的单卡离线情感交互与蒸馏规格 v1.1](../spec.md)

## Acceptance criteria

- [ ] 核查教师输出使用权限，教师回答与情绪、表达意图标签均作为待审材料，经过人工质量复核。
- [ ] 仅使用获准训练分区及其标签和提示示例；最终留出文本及其金标、开发样本均不作为训练或生成示例。
- [ ] 生成、重试、教师评审及后续轮次共用持久费用台账，累计不超过100元，不按每轮重新置零。
- [ ] 请求前按核实的计费规则保守核算额度，余额不足拒绝新请求；记录实际用量和费用，不保证固定样本数。
- [ ] 用可控服务验证重试和余额耗尽；完成还必须导出实际教师生成且经人工审核的材料和真实费用台账，仅模拟测试不能解锁训练。
- [ ] 可与原始学生基线并行，不等待数字人动画或工程验收；访问条件缺失时明确报告外部依赖。
