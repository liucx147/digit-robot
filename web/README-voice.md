# 文本、麦克风与数字人语音（任务 03 / 04）

本页在原本地音频、注视和测量入口之上增加显式连接的文本与麦克风轮次对话。页面初载不访问模型 API；原录音示例和本地文件仍可独立使用。运行时资源均来自仓库，本页不下载模型或调用云服务。

## 使用

从仓库根目录运行 `python -m http.server 5173 --bind 127.0.0.1 --directory web`，访问 http://127.0.0.1:5173/ 。先启动 A 的本地语音服务；实验主机部署和 SSH 隧道见 [A 接口说明](../docs/development/b-voice-api.md)。前端来源须在服务端允许列表内。页面只接受 localhost、127.0.0.1 或 IPv6 本机地址。

1. 点击“连接本地服务”。“本地服务连接”中默认地址为 `http://127.0.0.1:18000`，可按实际本机端口修改。重新连接开启新会话；同一连接的连续发送沿用服务端上下文。重连失败（包括地址无效）会禁用发送；修正地址后再次连接即可恢复，不会沿用旧会话。
2. 输入 1–2000 字中文，点击“发送并播放回复”。页面依次显示生成回复与语音、播放和完成；回复文字、用户文本情绪、数字人表达分别显示。
3. 若浏览器阻止自动播放，页面明确显示播放失败，可点击“播放音频”重试。停止会立即暂停本机音频、失效旧加载和动画，再请求服务端取消；取消失败仍保持停播，并要求重新连接。
4. “播放记录”可下载本轮 JSON，仅保存在当前页面。包含服务端原始回复、session_id、utterance_id、session_epoch 和每帧实际音频位置、归一化权重，供关联复核。请按需要自行保存；记录可能包含输入转写、回复与模型原始尝试，不会自动上传。

“载入中文录音示例”和选择本地音频会切回原本地音频流程，失效当前页面等待的语音回复。服务端仍可能计算已提交轮次；需要取消服务端工作时，请先点击“停止”。若停止确认尚未返回就切换本地示例或文件，页面会断开本地服务连接并提示重新连接，避免使用尚未同步的会话代次继续发送；迟到的停止确认不会恢复旧音频或覆盖本地状态。本地音频仍可独立播放；需要继续文本对话时，再点击“连接本地服务”开启新会话。本地音频继续使用手动微笑滑块；API 回复使用表达意图映射，滑块不覆盖该映射。摄像头和固定人脸入口沿用原说明，参见 [注视使用说明](README-gaze.md)。

## 实际表情与语音范围

用户文本情绪七分类只作为识别结果显示，不直接选择表情。TTS 的表达指令由服务端依据独立的 `expression_intent` 生成，当前 A 侧使用原始 Qwen3-TTS-12Hz-1.7B-CustomVoice；型号、固定音色、授权与实机基线以 [A 交接](../docs/development/b-voice-api.md) 和 `reports/voice-chain/` 为准。本次前端测试没有重新调用 GPU、训练 TTS 或证明四种指令的实际听感。

当前许可资产 VRM1_Constraint_Twist_Sample v1.0.1 只有已验证的 jawOpen、smile、blink 和眼球骨骼通道。实际 API 映射如下：

| style | 页面名称 / 服务端语气指令 | 进入控制层的微笑贡献 |
| --- | --- | --- |
| gentle | 温和关切 | 0.25 × intensity |
| cheerful | 轻快友善 | 0.85 × intensity |
| calm | 平静清晰 | 0（中性静态表情） |
| serious | 认真沉稳 | 0（中性静态表情） |

intensity 必须是 0–1 的有限数。calm 和 serious 在当前资产上使用相同中性脸型，不代表四种独立面部表情；gentle 与 cheerful 是同一 Joy 嘴部形变的不同强度。没有新增悲伤、愤怒等形变，也没有宣称七种表情。

嘴部先解码返回的实际 WAV，按全部声道的能量分析幅度；每帧读取真实 HTMLAudio 的 `currentTime`，采样对应 20 ms 窗口，停顿与结束时 jawOpen 为零。它是节奏开合，不是音素唇形。微笑实际权重为上述贡献再乘 `(1 - jawOpen)`，避免完全张嘴时叠加冲突；因此微笑静态姿态本身可能使嘴唇稍分开。表情、嘴部和注视最终都经原 FaceController 混合并实际渲染。

API 音频经 web 内独立客户端获取，再统一进入原解码/播放流程，客户端不直接写 audio.src。API 参数帧保留服务端 utterance_id 和 session_epoch，播放/加载另以本地 generation 隔离迟到结果；不会以本地 UUID 替换服务端发言标识。停止后不允许旧 HTTP、解码或媒体设备确认恢复播放。

## 错误与验证边界

连接或 HTTP 失败、GPU 繁忙、无效回复字段/表达枚举/强度、fallback、错误会话或代次、过期音频、损坏/全静音语音及实际时长与元数据不符均显示失败，不能显示成功。只接受与当前会话及发言匹配的服务端相对音频路径，避免把任意外部地址当本地语音加载。没有自动把失败替换成预录“成功”回应。

自动化边界仍为公开数字人页面和外部 HTTP/媒体设备接口：API 替身返回固定中文结构与明确标记的正弦/静音 WAV，真实 Chrome 播放、解码、Three.js 资产和 FaceController 不替换。`web/tests/voice-public.test.cjs` 的 22 项专项已通过，包含真实音频/画面、服务端标识记录、四 style 通道、错误和停止迟到，以及停止未确认时切换示例/文件、非法地址重连及恢复；忽略目录 `artifacts/ticket-03-*` 保存日志、截图和下载记录。运行方式沿用 [原页面测试](README.md)：

```powershell
node --test --test-concurrency=1 web/tests/public-page.test.cjs web/tests/gaze-public.test.cjs web/tests/measurement-page.test.cjs web/tests/voice-public.test.cjs
```

这 22 项专项不是实际 LLM/TTS 联合运行、人工语气与表情审阅、物理扬声器/屏幕同步、95%/200ms、30分钟20轮或完整500ms停止验收。完整既有浏览器回归与实际模型联合验证由集成阶段另行保留证据；任务03不在此关闭。麦克风04的候选实现见下文，完整停止验收留给05，异常恢复/离线整机等按各票验证。

数字人剩余工程估算见 [按功能重新拆分的估算](../docs/implementation/remaining-digital-human-estimate.md)。

## 麦克风轮次（任务04候选，2026-11-15）

连接本地服务后，点击“开始发言”，授权麦克风，说完点击“结束发言”。页面依次显示请求权限、录音、转换、转写、生成、合成、播放和完成，并显示ASR原文。结束发言只提交一次；本轮完成或停止前不能再次录音或发送文本，不实现边听边说或语音抢话。原本地音频与示例入口仍用于独立播放。

浏览器用MediaRecorder收集完整录音，在采样率16 kHz的AudioContext中解码并重采样，多声道取平均后编码为单声道16-bit PCM WAV。提交的是原始WAV字节，带Content-Type: audio/wav和X-Session-Epoch；不直接提交WebM/Opus。A端契约允许8–48 kHz、单/双声道PCM WAV，本页面统一发送16 kHz单声道。每轮最多30秒、6 MiB；达到时长上限取消本轮并提示重新发言。权限拒绝、不支持的浏览器/格式、空或全静音录音、无法转写与阶段超时均显示错误，不用空转写或预录音伪造成功。

“停止”在权限等待、录音、录制器结束回调、解码、API等待和播放阶段均先失效本轮并释放麦克风；迟到授权取得的轨道也会立即释放。摄像头仅请求video，麦克风仅请求audio；普通录音结束/失败不释放独立摄像头，全局停止仍按原流程一并停止注视。轮询只读取服务阶段，不推进本地发送代次；旧阶段、旧响应及旧播放确认不得覆盖新轮次。桌面头部保持有限高度，停止/播放条在滚动时可见；移动端恢复单列。

“发言响应计时”和手动下载的播放JSON中，input记录本轮speech_ended_at_ms、audio_started_at_ms及speech_end_to_audio_start_ms，关联原服务端发言ID与代次。时间来自结束按钮事件和真实HTMLAudio的playing事件，包含转换、网络、模型、解码与播放启动等待；这是浏览器软件观测，不是物理扬声器出声/屏幕同步，也不判断回复的意义或宣称三秒达标。后续文本轮次清理麦克风计时；重播保留首次响应计时。

前端不新增录音永久保存或自动下载，浏览器中间音频只用于当前轮次；A端既有运行目录与日志按其接口说明管理。手动下载的JSON可能包含转写/回复，未自动上传公共仓库。

自动化沿用公开页面及外部HTTP/媒体设备边界，使用明确标记的设备信号与API替身；MediaRecorder、解码、WAV编码、HTMLAudio、Three.js和FaceController真实运行。本候选麦克风专项24/24、既有页面/注视/测量/文本语音回归47/47通过；覆盖格式、各阶段、计时、空/静音/超限/权限/转写失败、停止与迟到结果、跨输入轮次和低分屏布局。日志及软件计时/截图保留在忽略目录artifacts/ticket-04-*；运行命令在原浏览器测试列表末尾加入web/tests/microphone-public.test.cjs。Windows测量回归须将PYTHON_EXE设为有效Python路径，避免失效的系统别名。

本候选未调用真实GPU或训练ASR/TTS。A侧模型许可、冻结版本和既有ASR能力见[A接口交接](../docs/development/b-voice-api.md)及reports/voice-chain/。固定中文录音经真实ASR/LLM/TTS与当前页面的联合验证、用户实际麦克风验收仍待集成执行；04保持未关闭，物理声画同步、完整500ms停止与连续运行仍按各票单独验收。
