# 本地档案与偏好

连接支持档案功能的本机服务后，“本地档案”区域提供创建与选择、改名、删除，以及“偏好称呼”和“交流偏好”的保存、读取与清空。可以选择匿名对话；匿名不会保存偏好。页面不从摄像头推断身份。

切换档案、创建、改名、修改或删除偏好前，页面立即停止当前音频、录音、动画与待下载的回复；等待服务确认期间不能开始新发言或另一项档案操作。成功后使用服务确认的当前会话继续交谈。失败会显示原因并保持对话暂停，可重新读取档案、重试操作或重新连接；旧回复不会继续播放。重新读取档案也会停止本机当前回复。

浏览器仅可保存所选档案 ID。档案名称、偏好和聊天不会写入浏览器持久存储；名称与偏好每次均读取本机服务。页面重新加载或服务重启后，点击“连接本地服务”会读取档案列表，创建新会话并明确绑定仍有效的选择。先前档案已被删除时会清除选择、显示提示并使用匿名对话。未支持档案的旧服务仍可使用原有匿名文本和语音对话。

A/B 接口的冻结来源是 [A 档案 API 契约（26c6b995）](https://github.com/liucx147/digit-robot/blob/26c6b995c165d14753612aed4dad8dc78cedbaad/docs/development/profile-api.md)。当前 B 分支不包含 A 的后端实现；需要与支持该契约的服务联调。

`profile-public.test.cjs` 通过真实页面、媒体播放及有状态的外部 HTTP 边界验证档案流程，不替换页面内部模块。覆盖两档案切换、偏好增查改删、服务端新值读取、重载、改名文本安全、删除、写入失败、重新读取恢复、实际音频立即停止、V1 下载取消、V2 播放与预取取消、跨会话 epoch、重连迟到结果及已删除的选择。它不证明真实模型遵循偏好，也不证明物理音画同步或整机离线验收。

```powershell
node --test web/tests/profile-public.test.cjs
```

使用 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH` 指定本地环境。默认使用浏览器默认渲染器，测试输出实际 WebGL 渲染器。需要明确的软件渲染对照时才设 `BROWSER_RENDERER=swiftshader`。
