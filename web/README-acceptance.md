# 页面验收记录：采集准备

这是事项 11 的采集准备入口。默认折叠、不采集、不创建验收草稿存储键。仅在首页展开“验收记录”、填写完整冻结代码 SHA 和运行条件后点击“开始本段采集”，才启用本机草稿保存。SHA 和真实组合条件均为操作者声明，页面不会验证代码或模型身份。三维头部及 renderer 尚未就绪时不能开始。

每段保存实际 asset 类型、版本、SHA、renderer/vendor/WebGL、浏览器信息、UTC 对照和单调时钟观测。它们帮助复核当时的软件环境，不证明单 5090、真实模型、物理声音/画面或完整离线运行。不得用该面板关闭事项 11 或宣称工程验收通过。

## 轮次与连续性

- 只记录本段开始后的新尝试。文字提交即输入结束；麦克风使用实际“结束发言”按钮时刻，等待权限不算发言结束。
- 一轮须经过尝试、有效输入结束、实际媒体播放时钟到达能量活动、整轮播放完成。首活动是软件能量观测，不证明语义、有意义语音或扬声器实际出声。
- 分句全部完成才算一轮；重播、本地文件、录音示例、停止、失败、部分播放和中途加入的旧轮次不增加完整轮数。失败及取消保留，不被后续成功替代。
- 每秒观测一次心跳。超过 5 秒的缺口、单调时钟倒退、UTC 与单调时钟差异超过 2 秒、页面隐藏/恢复都会保留事件并标记连续性待复核；未观测间隔不加到观测时长。不要使用浏览器休眠后的墙上时间补齐记录。
- “记录服务重启”结束当前段并标记待复核；“结束本段采集”只停止记录，不停止业务。重新开始建立新段。重载不自动采集；未结束的旧段标记中断。
- 30 分钟及 20 完整轮只在同一段内计算，15 分钟加 15 分钟不能合并。`software_candidate` 仅是软件计数候选；全部导出始终为 `engineering_acceptance: "not-assessed"`。故障、时钟异常和中断段不得作为连续性已通过证据。

## 本机保存、导出与隐私

草稿键为 `digitalhuman.acceptance-journal.v1`。只有显式采集之后才写入。恢复草稿只读取内存快照，逐字段校验并投影白名单，重新按段内事件计算完整轮数；不会改写其他页面正在使用的草稿，无效草稿可见且原存储不被覆盖。“清空本机验收草稿”是显式删除操作：即使正在采集，也会停止采集并丢弃全部当前/历史内存及本机草稿，操作前请先下载。完整 JSON 下载包含所有段、失败、停止、重启及连续性事件。不要将真实实验记录自动上传仓库。

同源页面使用浏览器 Web Locks 保证单一草稿写入所有者：只有明确开始采集或清空时才申请，不因默认打开页面占用。所有者结束本段、保存失败或清空后仍持有权限，直到关闭、刷新或离开页面。其他页面仍可下载自己的内存快照，但开始或清空会显示冲突且不改写草稿；快照不是其他页面的实时采集状态。请先下载所有者页面的记录，再关闭或刷新它；其他页面随后手动开始时会在取得权限后重新读取最新草稿，保留旧段及已保存的故障，并建立新段。清空后的旧快照不能复活已删除历史。浏览器不支持 Web Locks（包括不能提供该能力的页面环境）时，验收采集与清空不可用并显示原因；下载、对话、播放、停止和档案功能照常。

事件仅允许 client_turn_id、session_id、utterance_id、epoch、输入来源、固定阶段/结果枚举及数值时序。session_id 只用于关联 A/B 软件观测，并非账户身份。此记录不保存发言、转写、回复、姓名、profile_id、偏好、错误原文、音频/资产文件路径或服务地址。页面中原有的“播放记录”是另一个入口，可能包含回复和文件名；不要将它与本面板的非内容草稿混淆。

总记录超过 10,000 个事件或 JSON 超过 2,097,152 个字符时，采集停止且界面提示容量已满；触发前后内存事件完整保留，旧段不截断。存储配额、写入或清空故障同样停止采集，保留草稿权限与内存导出，不自动重试，不阻断原音频停止、取消或后续业务交互。请立即下载内存记录；修复浏览器存储问题后，只有显式“清空本机验收草稿”才会删除草稿并允许重新开始。失败时未成功写入的最新内存事件可能在关闭页面后丢失。

## 后续真实验收证据

面板不代替事项 11 的独立采集清单：冻结完整模型/软件/资产/配置，真实组合连续运行至少 30 分钟且至少 20 轮；保留全部失败与重启；用原始音画证据复测嘴部同步、物理停止、断网启动、档案操作与隔离、人脸注视和异常恢复，并记录资源使用。响应三秒优化项单列，不改变首次工程验收门槛。已有同步物理采集准备见 [README-measurement.md](README-measurement.md)。当前面板实现不改变任何模型、生产 API、部署或 GPU 安排。

## 软件回归

公开页面测试：`node --test web/tests/acceptance-journal-public.test.cjs`。测试从真实页面点击，通过外部 HTTP 模型替身、实际 HTMLAudio、固定录音、浏览器时钟及存储边界验证记录逻辑，不直接派发伪造的应用生命周期。加速 30 分钟、合成音和固定录音均只验证软件逻辑，不能当作真实 30 分钟运行、中文语音质量或物理同步证据。

Windows 本地运行需按现有浏览器测试约定配置 `PLAYWRIGHT_MODULE` 与 `CHROME_PATH`，使用默认 renderer，不强制软件渲染。开发红绿原始日志保存在被忽略的 `artifacts/b-acceptance-journal/`；跨页面所有权复现、修复及兼容回归日志和命令见 `artifacts/b-acceptance-journal-review/`。同一浏览器上下文的两个页面共享真实 localStorage，验证恢复只读、互斥开始、冲突清空、失败保留权限和旧快照接管；这些软件替身证据与真实验收记录分别保管。
