## 已验证的初期环境

2026年11月13日通过用户提供的SSH主机核验：NVIDIA GeForce RTX 4090 D，24564 MiB；Conda Python 3.12.3；PyTorch 2.8.0加CUDA 12.8。一个256乘256矩阵乘法已在CUDA上完成且结果有限。

4090D是本阶段开发环境，以上不是模型推理性能或最终5090验收结果。浏览器渲染发生在访问页面的客户端，远端负责提供静态资源。

远端专用目录为 `/root/autodl-tmp/digital-human-b`，Git工作副本为其中的 `project`。代码统一集成到 `integration/digital-human-v1`；任务分支经独立测试后合并。

## 启动与访问

远端使用已有Conda Python，服务仅绑定回环地址。在项目根目录运行：

```bash
/root/miniconda3/bin/python -m http.server 8765 --bind 127.0.0.1 --directory web
```

当前会话已启动该服务，日志在专用目录的 `preview.log`，进程号记录在 `preview.pid`。重新启动前核实端口与进程属于本项目。

本机使用用户自己的SSH地址建立端口转发：

```bash
ssh -N -p <SSH端口> -L 127.0.0.1:8765:127.0.0.1:8765 root@<SSH主机>
```

随后打开 <http://127.0.0.1:8765/>。SSH地址和认证配置由开发者本机管理，不写入应用源码。

## 本地音频说话头

点击“载入中文录音示例”，再点击“播放音频”；也可选择浏览器能够解码的本地音频。示例是有明确许可的“你好”录音，并非模型生成或TTS。声音播放时观察嘴部开合，停顿与结束时闭嘴；“停止”使当前播放和旧代次动画失效。

微笑强度通过同一面部控制层混合。播放记录可以展开、下载，包含发言、代次、帧序号、音频相对时间与归一化权重。记录只保留在页面内，本地音频不因这项功能上传服务器。

01功能已在集成后通过11项公开浏览器测试，并经远端服务和SSH隧道复验。测试观察真实WebGL画面、浏览器音频播放和导出记录；这不是95%声画同步、扬声器回采或30分钟完整模型交互的验收。
