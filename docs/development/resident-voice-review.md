# 常驻分句语音审查

基点7251b70，审查提交2b4a80a；code-review规范轴和需求轴分别由独立只读审查执行。

## Standards

两项P2：句间间隔在实际playing之前计时；流式客户端没有约束分句总数、累计字符及done文本一致性。

## Spec

一项P2（与规范轴计时问题部分重叠）：播放完成后迟到的done会被计入total_playback_ms，违背实际媒体播放计时的约定。

## 修复与验证

按前段实际ended、后段实际playing记录间隔；按最后实际ended计算总播放延迟，独立保留done到达时间。客户端严格配对sentence/audio_ready，最多三句、最多80字，done.reply必须与分句连接后的文本一致，校验在音频预取之前执行。

新增四项公开页面回归：第二段延迟500ms起播、播放完成后done迟到700ms、超出三段、最终文本不一致。四项在修复前全部失败，修复后与原有四项分句回归共8项全部通过。最终完整套件及4090性能证据另见实施报告。未新增模型权重或密钥。
