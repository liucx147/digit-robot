# A 侧语音链路与 B 接口实施计划

依据：用户要求公开仓库代码、在 4090 串起 ASR→情感对话→TTS 并交接 B；现行规格 v1.1。审查固定点为 cf6870f。

## 设计与边界

复用原始学生 DialogueSession 和已实测的语音脚本，以子进程运行三个隔离环境，逐阶段释放模型。服务提供会话、文本/WAV 输入、状态、音频获取、停止和重置。单卡同时只接受一个推理轮次；模型无效输出或语音失败均返回可见失败，不交付伪成功音频。

接口采用 FastAPI，默认仅监听 127.0.0.1，B 经 SSH 隧道接入。WAV 输入为 16-bit PCM、1/2声道、8–48kHz、最多30秒及6MiB。表达意图使用现有四类 style；输出 WAV 时长、采样率和 URL 与同一发言/代次关联。播放时间和动画由 B 依据 audio.currentTime 同步。

停止/重置立即推进代次并使旧轮次失效；阶段进程在取消时终止。重置清除对话，停止保留已完成对话。音频获取也校验当前代次。服务尚不宣称浏览器500ms停播、三维呈现或完整工程验收。
