# A 后端设计

用户已明确委托SQLite、API契约、代次隔离、后端停止恢复及部署准备；实施遵循其执行提示，不重新请求已授权设计选择。

采用SQLite独立ProfileStore，VoicePipeline拥有档案与会话协调锁，串行和分句管线复用同一偏好快照与取消边界。相比仅浏览器存储，SQLite满足重启后持续；相比在聊天历史追加偏好，独立快照和mutation清空历史更容易验证删除不复活。具体HTTP行为见docs/development/profile-api.md。

修改偏好、切换档案、删除档案必须先成功写事务，再在同一协调锁内取消绑定会话、清除历史并推进epoch；正在运行的轮次只可发布同一epoch结果。数据库只保存手动偏好，不自动保存聊天。profile不是身份认证。本次不改B的web或测量源码，不启动研究，不承诺物理验收。

主要验证：两个档案隔离；v1/v2提示快照；历史污染后的更新与删除；数据库重启与故障原子性；修改时在途生成失效；超时/停止/断连后新轮次；旧接口与匿名会话兼容。4090真实模型验证使用合成档案和受控测试窗口，保留原服务与模型。
