# 中性实体三维头部

2026-11-15。依据用户最新修正：卡通人物与机械外露造型都不要，模型做成立体的。替换默认外观为素色、中性比例的头颈雕塑，完整封闭后脑与侧面；提供拖动旋转、滚轮缩放、正侧背与复位按钮。保留现有面部参数、音频时钟、麦克风与注视接口。

实现选择：在现有本地Three.js中生成网格，避免外部模型下载和新增许可/费用。使用柔和陶瓷材质与有方向的布光；嘴部形变和眼球骨骼接入同一FaceController。不是写实肖像或医学建模。用户没有指定性别或具体人物，采用中性无发型设计是本次实现选择，可按预览进一步调整。

现有VRM仅留在带明确历史标识的09测量基线中，旧基线不证明新模型声画同步。新默认模型必须重新采集同步验收。
