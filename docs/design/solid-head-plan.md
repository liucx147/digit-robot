# 实体头部实施计划

**Goal:** 默认显示可从各面查看的中性实体头部，保持语音开合与眼动。
**Architecture:** 本地程序网格接入FaceController，视角控制只移动相机，不写面部权重和播放状态。
**Tech Stack:** 现有Three.js、浏览器Pointer/Wheel/Keyboard、Playwright公开页面。
**Spec:** solid-head-design.md；项目spec.md的声音/参数/离线规则继续适用，外观以用户最新修正为准。

1. 公开页面旋转测试先红：默认模型名、侧背像素变化、复位一致、拖动/缩放可操作。
2. 实现solid-head.js与avatar.js中接入和相机控制，更新默认清单与按钮、说明。
3. 旋转测试转绿；运行原公开音频、注视、语音与麦克风回归，保持旧测量基线明确标识。
4. 目视检查正侧背截图；记录新模型尚未物理同步验收，部署预览并共享提交。

Review focus: 触屏滚动/旋转、窄屏按钮、缩放限位、播放中转动不取消声音、旧模型测量证据不混用。
